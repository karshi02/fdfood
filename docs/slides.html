จองโต๊ะล่วงหน้า

  1. แตะโต๊ะที่ ว่าง
  2. กรอกวัน-เวลา และจำนวนคน
  3. กด จองโต๊ะ โต๊ะเปลี่ยนเป็นสีส้ม
  4. แก้ข้อมูลได้ด้วย บันทึกการจอง หรือกด ยกเลิกการจอง

เปิดโต๊ะเมื่อลูกค้ามาถึง

  1. กดปุ่ม กดเปิดโต๊ะ (โต๊ะว่าง) หรือ เปิดโต๊ะ (โต๊ะที่จองไว้)
  2. ใส่ จำนวนลูกค้า (ต้องใส่ · โต๊ะที่จองไว้กรอกให้แล้ว) เลือก ทานที่ร้าน หรือ สั่งกลับบ้าน แล้วกด เปิดโต๊ะ / เริ่มสั่งอาหาร
  3. กดเมนูจานแรก โต๊ะจึงเปลี่ยนเป็น "มีลูกค้า" และเริ่มนับเวลา (ข้อมูลการจองยังอยู่)
เปิดผิดโต๊ะ? ถ้ายังไม่ได้สั่งอะไร แค่กดปิด โต๊ะกลับเป็นว่าง (หรือจองไว้) เหมือนเดิม · ลดจานสุดท้ายออกแล้วปิด ก็กลับเป็นว่างเช่นกัน
เจ้าของร้าน ใส่วัน-เวลาเปิดโต๊ะ / เวลาสั่ง / วัน-เวลาชำระย้อนหลังได้ (เว้นว่าง = ตอนนี้) ใช้ลงบิลที่ลืมคีย์
