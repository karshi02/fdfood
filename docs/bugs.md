### อื่นๆ — fdfood-6b ✅
- ราคา/ส่วนลด/เงินรับ/รายจ่ายใหญ่เกิน `DECIMAL(10,2)` → เดิม error 500 → ตอนนี้ `money()` ตรวจก่อน (รวม `menu_bulk` ที่เดิมรับราคาติดลบได้)
- คุกกี้ session ไม่มี `secure` บน HTTPS → เพิ่มแล้ว (ดู `X-Forwarded-Proto` → nginx ต้องตั้ง `proxy_set_header X-Forwarded-Proto $scheme;`)
- Service/VAT รับข้อความอะไรก็ได้ → บังคับตัวเลข 0–100
- จำนวนคนจองเกิน INT → จำกัด 1–999
- วันที่รายจ่ายแบบ `2026-02-31` → ตรวจด้วย `checkdate`
- body JSON ที่ไม่ใช่ object (เช่น `"abc"`) → เดิม 500 → ตอนนี้ถือเป็น `{}`
- migration (ALTER/CREATE) รันทุก request → ตอนนี้รันเฉพาะเมื่อ `meta.schema` ต่ำกว่า `SCHEMA`
- ช่องรับเงินถูกล้างเมื่อเครื่องอื่นแก้ข้อมูล (poll re-render) → จำค่าไว้ใน `cashIn` (`js/table.js`)
- พิมพ์ส่วนลดเป็นข้อความ เช่น "abc" → เดิมลบส่วนลดเงียบๆ → ตอนนี้เตือน
- Dockerfile ใช้ `php.ini-production` (ไม่โชว์ error บนหน้าเว็บ) + ซ่อนเวอร์ชัน PHP/Apache
