# โคขุน POS

ระบบขายหน้าร้านสำหรับร้านปิ้งย่างเนื้อโคขุน ใช้ผ่านเว็บเบราว์เซอร์ได้ทั้งคอม แท็บเล็ต และมือถือ ทุกเครื่องเห็นโต๊ะและออเดอร์ตรงกัน (ซิงก์ทุก 3 วินาที)

PHP 8 + MySQL/MariaDB + JavaScript ล้วน (ไม่มี framework, ไม่มีขั้นตอน build) รันใน Docker

## ทำอะไรได้บ้าง

- **โต๊ะ**: เปิดโต๊ะ (จำนวนลูกค้า, ทานที่ร้าน/สั่งกลับบ้าน), จองโต๊ะ, ย้าย/รวมโต๊ะ, โต๊ะเปิดจริงเมื่อสั่งจานแรก
- **สั่งอาหาร**: ค้นหาเมนู, แยกหมวด, หมายเหตุต่อจาน, ส่งครัว (พิมพ์ใบครัว), เพิ่มเมนูใหม่จากหน้าโต๊ะได้ (รออนุมัติราคา)
- **ชำระเงิน**: เงินสด (คิดเงินทอน), โอน (QR พร้อมเพย์), อื่นๆ, เงินสด+โอนในบิลเดียว, ส่วนลด, Service charge, VAT
- **พิมพ์บิล**: เครื่องพิมพ์ทั่วไป, เครื่องพิมพ์ Bluetooth, เครื่อง POS Android ผ่านแอป RawBT (Ocha / Sunmi)
- **ยอดขาย**: เลือกช่วงวันจากปฏิทินไทย, รายการบิล, เมนูขายดี, ยอดตามหมวด, พิมพ์บิลรวม
- **แดชบอร์ด**: รายรับ / รายจ่าย / ค้างรับ / กำไร, กราฟรายวัน, บันทึกรายจ่าย
- **ผู้ใช้**: เจ้าของร้านมีสิทธิ์ทุกอย่าง พนักงานกำหนดสิทธิ์ได้ทีละข้อ (แก้เมนู, ส่วนลด, ลดรายการที่ส่งครัวแล้ว, ดูยอดขาย, ยกเลิกบิล, ตั้งค่าร้าน, จัดการผู้ใช้)
- **เฉพาะเจ้าของร้าน**: ลงวันเวลาย้อนหลังตอนเปิดโต๊ะ / สั่ง / ชำระ, เปลี่ยนวันหรือวิธีชำระของบิล, เปิดบิลที่จ่ายแล้วเพื่อชำระใหม่

คู่มือการใช้งาน (ภาษาไทย): [docs/slides.html](docs/slides.html) และ [PDF](docs/โคขุน-POS-คู่มือการใช้งาน.pdf)

## รันบนเครื่องตัวเอง

ต้องมี [Docker Desktop](https://www.docker.com/products/docker-desktop/)

1. สร้างไฟล์ `.env` ไว้ที่โฟลเดอร์โปรเจกต์ แล้วตั้งรหัสผ่านฐานข้อมูลเอง:
   ```
   DB_PASS=ตั้งรหัสเอง
   DB_ROOT_PASS=ตั้งรหัสเองอีกอัน
   ```
2. Windows: ดับเบิลคลิก `start.bat` หรือใช้คำสั่ง:
   ```
   docker compose up -d --build
   ```
3. เปิด http://localhost:8090
   - แท็บเล็ต/มือถือที่ต่อ WiFi เดียวกัน: `http://IP-ของเครื่องนี้:8090`
   - phpMyAdmin (ดูฐานข้อมูล, เปิดได้จากเครื่องนี้เท่านั้น): http://localhost:8091
4. เข้าระบบครั้งแรกด้วย `admin` / `admin1234` ระบบจะบังคับให้เปลี่ยนรหัสผ่านก่อนใช้งาน

ปิดระบบด้วย `stop.bat` ส่วน `backup.bat` ใช้สำรองฐานข้อมูลไว้ที่โฟลเดอร์ `backups/` (เก็บย้อนหลัง 60 วัน)

## โครงสร้างโปรเจกต์

```
public/
  index.html      หน้าเว็บทั้งหมด (แอปหน้าเดียว)
  api.php         API ทั้งหมด: login, โต๊ะ, ออเดอร์, ชำระเงิน, รายงาน, ผู้ใช้
  js/             core (ซิงก์ข้อมูล), render (โต๊ะ/เมนู), table (หน้าสั่ง/ชำระ),
                  report, dashboard, calendar, print, btprint (Bluetooth / RawBT)
  css/            app, sheet, dash, calendar, bottomnav, press
db/init.sql       โครงสร้างฐานข้อมูลตอนติดตั้งครั้งแรก
Dockerfile        PHP 8.3 + Apache
docker-compose.yml        สำหรับรันบนเครื่องตัวเอง
docker-compose.prod.yml   สำหรับเซิร์ฟเวอร์จริง (app 2 ตัวหลัง nginx)
deploy.sh / backup.sh     deploy และสำรองข้อมูลบนเซิร์ฟเวอร์
```

ฐานข้อมูลที่ติดตั้งไว้แล้วจะอัปเกรดตัวเองตอนมี request แรกหลังอัปเดตโค้ด (ดู `SCHEMA` ใน `api.php`) จึงไม่ต้องรัน migration เอง

## Deploy ขึ้นเซิร์ฟเวอร์

`./deploy.sh` (รันจาก Git Bash) จะส่งโค้ดที่ push ขึ้น `origin/main` แล้วไปที่เซิร์ฟเวอร์ ไม่ใช้ไฟล์ที่ยังแก้ค้างในเครื่อง ทุกครั้งที่ deploy:

- สำรองฐานข้อมูลก่อน ถ้าสำรองไม่สำเร็จจะหยุด deploy
- ตรวจ syntax ของ PHP
- สลับเวอร์ชันแบบไม่มี downtime (โฟลเดอร์ `releases/<hash>` + สลับ symlink)
- ผู้ใช้ไม่หลุดออกจากระบบ (session เก็บใน volume)
- ถ้าทดสอบหลัง deploy ไม่ผ่าน จะสลับกลับเวอร์ชันเดิมให้อัตโนมัติ

## ข้อควรระวัง
